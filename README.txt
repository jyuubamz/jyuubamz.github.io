K-Pop Agency Simulator
======================
Upload this whole folder to your GitHub Pages repo (e.g. /kpop-agency-sim/)
and open index.html. Keep all 12 files in the same folder.

Files: index.html, style.css, data.js, sim.js, actions.js, views1.js,
views2.js, views3.js, editor.js, inbox.js, life.js, staff.js

Saves are stored in the player's browser (localStorage).
